# Open Source Contribution Tracker

A public log of my journey into open source — every issue, PR, and badge along the way.

## Why this repo exists

- Track every open source contribution I make (docs, bugs, features)
- Keep myself accountable with a visible streak
- Help others follow the same path (see [ROADMAP.md](ROADMAP.md))

## Badge progress

| Badge | Status | Notes |
|---|---|---|
| Quickdraw | 🎯 | Closed an issue within 5 minutes of opening it |
| Pull Shark | 🦈 | Merged PRs in public repos |
| Pair Extraordinaire | 🤝 | Merged PR with `Co-authored-by:` credit |
| Galaxy Brain | ⏳ | Goal: accepted answers in repo Discussions |
| Starstruck | ⏳ | Long-term: a repo people actually star |

## How I use it

1. Pick an issue from a real project ([goodfirstissue.dev](https://goodfirstissue.dev))
2. Log it in [contributions/LOG.md](contributions/LOG.md) before starting
3. Ship the PR, link it back, update the status
